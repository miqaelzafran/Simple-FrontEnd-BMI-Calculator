# BMI Calculator 🏋️‍♂️

A lightweight, clean, and responsive Body Mass Index (BMI) calculator web application built using **HTML5**, **CSS3**, and **Vanilla JavaScript**. 

## Features ✨
- **Personalized Input:** Users can input their name, height (in cm), and weight (in kg)[cite: 14].
- **Instant Calculation:** Computes the BMI value instantly using standard metric formulas.
- **Category Classification:** Automatically categorizes results into *Underweight*, *Normal weight*, *Overweight*, or *Obese*.
- **Responsive Design:** Styled with a modern, centered card layout and smooth hover effects for a clean user experience[cite: 16].

## Built With 🛠️
- **HTML5** – Structure of the web page[cite: 14]
- **CSS3** – Styling, layout, and responsiveness[cite: 16]
- **JavaScript (ES6)** – DOM manipulation and BMI logic

## Getting Started 🚀
To run this project locally, follow these simple steps:

1. Clone or download this repository to your local machine.
2. Open the project folder.
3. Double-click on `index.html` to open it in any modern web browser.
